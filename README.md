# Callum Rider Tutoring

Standalone static tutoring website for Callum Rider, a 16-year-old sixth-form student offering Maths & English tuition.

## Files
- `index.html`
- `style.css`
- `script.js`
- `assets/logo.png`
- `assets/favicon.png`

## Before publishing
Open `script.js` and replace:

`callumrider@icloud.com`

with the email address you want parents to use.

The enquiry form then opens the visitor's normal email app with the enquiry filled in. This version does not store enquiry details.

## GitHub Pages
Upload the files to a GitHub repository and enable GitHub Pages for the repository.

When you buy your domain, GitHub Pages can be connected to it through the repository's Pages settings and your domain's DNS settings.
